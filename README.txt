SKYWINGS TRAVEL WEBSITE

Files:
- index.html: halaman website lengkap
- styles.css: styling modern dan responsive
- main.js: interaksi menu, reveal animation, testimonial slider, booking modal, subscribe validation

Cara menjalankan:
1. Ekstrak folder ini.
2. Pastikan index.html, styles.css, dan main.js tetap berada di folder yang sama.
3. Buka index.html di browser atau gunakan Live Server di VS Code.
4. Koneksi internet diperlukan untuk Google Fonts, Remix Icon, Swiper, dan gambar Unsplash.

Catatan:
- Form booking dan subscribe adalah demo front-end. Data belum dikirim/disimpan ke server.
- Untuk booking nyata, sambungkan form ke backend/API dan gunakan endpoint yang aman.
- Gambar memakai URL Unsplash, jadi memerlukan koneksi internet.
